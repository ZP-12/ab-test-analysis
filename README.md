# 电商平台功能改版 AB 测试效果评估

## 项目简介
基于电商用户行为数据，模拟真实业务场景下的功能改版 AB 实验，使用 SQL 完成多表关联与分层取数，通过 Python 进行统计假设检验与异质性分析，评估实验显著性并输出分层上线策略建议。

## 技术栈
- **SQL**：多表查询、分组聚合、窗口函数（NTILE）
- **Python**：Pandas（数据清洗/透视）、NumPy、Matplotlib、Scipy（卡方检验/t 检验）
- **分析方法**：AB 测试、假设检验、置信区间、异质性分析、描述性统计

## 核心结论
- 实验组转化率相对对照组提升约 **25.66%**，卡方检验结果统计显著（p &lt;&lt; 0.05）
- 实验组人均收入增长显著，t 检验 p 值 &lt; 0.05
- **异质性发现**：
  - iOS 用户转化率提升效果最优，建议优先全量上线
  - 老用户响应度高于新用户，改版对成熟用户更友好
  - 一线城市用户转化提升最明显
- 业务建议：对 **iOS + 老用户 + 一线城市** 人群优先全量上线，其余人群持续观察
